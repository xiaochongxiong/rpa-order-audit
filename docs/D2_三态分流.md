## 一、今天要理解的三件事（够用，不用背）

### 1. 三态是什么，为什么是三态不是两态

| 态 | 含义 | 后续动作 |
|---|---|---|
| **自动通过** | 常规单，规则全不命中 | 系统直接放行，人不用看 |
| **转人工** | 软异常（信息不全/备注特殊/退货多） | 进人工队列，人核对后再决定 |
| **自动拦截** | 硬违规（金额矛盾/低于成本/超卖） | 直接拦下，不允许发货 |

**为什么必须三态**：只有"通过/不通过"两态，会把"地址缺个区"这种小问题和"超卖"这种大问题混为一谈。三态是审单 SOP 的标准抽象——**机器处理常规、人只处理灰色地带、硬违规直接掐断**。这是"系统自动执行 + 人处理异常"的落地形态。

### 2. 优先级：一单命中多条时听谁的

**自动拦截 > 转人工 > 自动通过**。例如 O008 实付 0（R1）且低于成本（R2），命中两条硬规则，仍只判一次"自动拦截"。规则引擎必须显式实现这个优先级，否则同一单可能被判两次、写两行。

### 3. 判定逻辑放在哪：Python 代码节点

影刀做判断有两条路，今天选第二条：

| 路径 | 做法 | 为什么选/不选 |
|---|---|---|
| 纯指令拖拽 | 用「如果/否则如果」指令搭 7 条规则 | 能做，但 7 条规则嵌套 3 层、改一次要动一堆连线，维护难 |
| **Python 代码节点** ✅ | 拖一个「执行 Python 脚本」指令，贴一段判定函数 | 规则集中在一处、可读可改；你有 Python 基础，正好呼应之前讲的"复杂逻辑嵌 Python 补充" |

**重要事实（已核实）**：影刀社区版支持 Python 代码节点。指令名叫「**执行 Python 脚本**」（不是"Python 模块"），拖出来后左侧代码区、右侧输入/输出变量映射区。你现在是**创业版试用期，内置 Python 环境可直接用**；将来转社区版若报"环境未配置"，去影刀设置里手动指定本机 Python 路径即可（本机 Python 3.13 在 `C:\Users\jjchen\AppData\Local\Programs\Python\` 下，或命令行 `where python` 查）。

## 二、判定规则（代码就是按这个写的）

**自动拦截（硬违规，命中任一即拦截）**
- R1：实付金额 = 0 且 付款状态 = 已支付
- R2：实付金额 < 成本 × 数量
- R3：数量 > 可用库存

**转人工（软异常，命中任一即转人工）**
- M1：手机号不是 11 位纯数字
- M2：省 / 市 / 区 / 详细地址任一为空
- M3：备注含「转寄 / 代收 / 自提」任一关键词
- M4：历史退货次数 ≥ 3

**自动通过**：以上都不命中。

> 实测备注：O008 同时命中 R1 + R2（实付 0 也低于成本），预期结果文档只标了 R1。判定结果不受影响（都是拦截），但你对照时会看到代码输出 `R1,R2`——这是代码更完整地报告了命中项，不是错误。
