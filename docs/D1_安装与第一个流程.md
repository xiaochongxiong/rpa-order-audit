## 第二部分：认识设计器界面（4 个区，2 分钟扫一遍）

| 区域 | 位置 | 干什么 |
|---|---|---|
| 指令区 | 左侧 | 所有能拖的"积木"（Excel、条件、循环…） |
| 画布区 | 中间 | 把指令拖进来，从上到下排成流程 |
| 属性区 | 右侧 | 选中某条指令后，在这里填参数 |
| 日志区 | 底部 | 运行时输出、报错都在这里——**排错看这里** |

三个概念（够用，不用背）：
- **指令** = 一块积木 = 一个动作（如"读取 Excel"）
- **应用 / 流程** = 若干指令按顺序串起来（新版界面里叫"应用"，旧教程叫"流程"，同一个东西）
- **变量** = 装数据的盒子（读进来的表格就存在变量里）

## 第三部分：搭第一个流程（照着拖，约 15 分钟）

### 步骤 1：新建应用（按新版界面，两步）
1. 点顶部「新建」→ 在「自动化应用」分类下选「**PC 自动化应用**」（操作电脑选它；手机自动化应用是操作手机的，今天不用）。
2. 弹出「**选择应用搭建模式**」窗口，三选一：

| 模式 | 说明 | 今天选哪个 |
|---|---|---|
| **自定义搭建** | 拖拽指令搭建，功能最全、适用范围最广 | ✅ **选这个** |
| AI 对话搭建 | 与 AI 对话自动生成，适合零基础 | ✗ 不选——后面要做规则判断，AI 生成的你改不动 |
| 智能录制搭建 | 录制鼠标操作生成流程，适合固定连续动作 | ✗ 不选——录不出"按条件分流" |

3. 进入设计器后，应用名改为 `订单审核_D1_读写测试`。

> **为什么坚持选"自定义搭建"**：D2 要做 if/else 三态分流，只有自定义模式能精确控制每条规则和变量；另两种模式生成的东西你看不懂也改不动，学不到东西。要实践"把 SOP 拆成规则再编排"，前提就是自定义搭建。
>
> 另外：Excel 自动化是**先打开成对象、再基于对象读写、最后另存**，不是"一步读文件/写文件"。

### 步骤 2：拖入「打开/新建 Excel」（打开源文件）
- 左侧指令区搜 `打开` → 找到「**打开/新建 Excel**」→ 拖到画布。
- 属性区：
  - 打开方式：打开已有 Excel
  - Excel 路径：`C:\Users\jjchen\WorkBuddy\2026-11-02-18-03-51\rpa-order-audit\data\模拟订单.xlsx`
  - **保存 Excel 对象至**：`源表`（后面两条指令都引用它）
    - ⚠ 这是**文本输入框、不是下拉框**：框里默认有 `excel_instance`，把它全选删掉，直接打字输入 `源表` 再确定。影刀的变量是"起名定义"的——输入什么名字就创建什么变量；下一步「读取 Excel 内容」里的"Excel 对象"才会变成下拉让你选这个名字。

### 步骤 3：拖入「读取 Excel 内容」
- 指令区搜 `读取 Excel` → 找到「**读取 Excel 内容**」→ 拖到下面。
- 属性区：
  - Excel 对象：选 `源表`
  - 读取方式：**已使用区域内容**（返回二维列表，含表头）
  - Sheet 页名称：Sheet1
  - **保存 Excel 数据对象至**：`订单数据`
  - 勾选「读取单元格显示的内容」（否则整数 2 会被读成 2.0）

### 步骤 4：拖入「打开/新建 Excel」（新建目标文件）
- 再拖一条「打开/新建 Excel」到下面。
- 属性区：
  - 打开方式：**新建 Excel**
  - **Excel 文件路径**：`C:\Users\jjchen\WorkBuddy\2026-11-02-18-03-51\rpa-order-audit\data\审核结果.xlsx`
    - ⚠ **必填，不能清空**：影刀新建 Excel 时必须知道新文档对应哪个文件，路径空着指令会显示红色叉号、无法运行。与步骤 6 的"另存为"路径填同一个文件即可（新建时占好位置，另存时把写入的数据落盘），不会冲突。
  - **保存 Excel 对象至**：`结果表`

### 步骤 5：拖入「写入内容至 Excel 工作表」
- 指令区搜 `写入内容` → 找到「**写入内容至 Excel 工作表**」→ 拖到下面。
- 属性区：
  - Excel 对象：选 `结果表`
  - 写入范围：**区域**
  - 行号：`1`，列名：`A`（从 A1 开始写）
  - 写入内容：选变量 `订单数据`（二维列表整块写入）
  - Sheet 页名称：Sheet1

### 步骤 6：拖入「保存/另存 Excel」
- 指令区找到「**保存/另存 Excel**」→ 拖到下面。
- 属性区：
  - Excel 对象：选 `结果表`
  - 保存方式：另存为
  - 路径：`C:\Users\jjchen\WorkBuddy\2026-11-02-18-03-51\rpa-order-audit\data\审核结果.xlsx`

### 步骤 7：拖入「关闭 Excel」×2（可选，建议加）
- 两条「关闭 Excel」分别关闭 `源表` 和 `结果表`，释放文件占用。

### 步骤 8：运行
点顶部「运行」→ 看底部日志区是否出现「执行成功」→ 打开 `data/审核结果.xlsx`。

**完成标志**：`审核结果.xlsx` 有 17 行（1 表头 + 16 订单），内容与原表一致。✅

### 实测验收记录（2026-11-18 20:27）

用户实操运行后，用 `openpyxl` 逐行比对源表与结果表，结果：

| 项 | 实测值 | 判定 |
|---|---|---|
| 结果表行数 | 17（1 表头 + 16 订单） | ✅ 达标 |
| 列数 | 18 | ✅ 与原表一致 |
| 表头 18 列 | 逐字相同 | ✅ |
| 业务字段值（订单号/平台/ buyer/地址/金额/数量/库存/备注…） | 16 单全部一致 | ✅ |
| 数量列 | 整数 2/3/10…（未变 2.0） | ✅ 说明"读取单元格显示的内容"已勾 |

**发现两处存储层差异（无害，可接受）**：
1. **空字符串 → 空单元格**：原表备注/区列的空值是 `''`，结果表读回是 `None`。两者都表示"无内容"，Excel 里肉眼一致，无需处理。
2. **手机号文本 → 数值**：原表手机号是文本 `'13800138001'`，结果表是数字 `13800138001`。值一致；11 位未超 Excel 15 位精度、无 0 开头号码，故无精度损失。D2 若要按位数判断手机号，读**源表**（仍是文本）即可，不受此影响。

结论：D1 目标"数据进得来、出得去"达成，进入 D2。

## 第四部分：卡住了怎么办（按顺序自查）

| 现象 | 先看这里 |
|---|---|
| 读取/写入报"对象不存在" | **「关闭 Excel」放错位置了**——对象要在所有读写完成后才关，关闭指令只能放流程最后，不能夹在中间 |
| "保存 Excel 对象至"找不到"源表"可选 | 那是输入框不是下拉框：删掉默认的 `excel_instance`，直接打字输入 `源表` |
| 新建后没找到"空白流程" | 新版界面没有这个入口，走「新建 → PC 自动化应用 → 自定义搭建」 |
| 弹出三种搭建模式不知选哪个 | 选「自定义搭建」——只有它能做 if/else 规则，另两种适合零基础/固定录制 |
| 找不到指令 | 指令区用搜索框搜关键词，别翻分类；**官方名是"打开/新建 Excel""读取 Excel 内容""写入内容至 Excel 工作表""保存/另存 Excel"** |
| 报"文件不存在" | 路径是不是少复制了、是不是用了正斜杠——Windows 用反斜杠 `\` |
| 读进来的变量是空的 | 「读取方式」是否选了"已使用区域内容"；变量名是否和下一步引用的一致 |
| 输出表只有表头没数据 | 写入指令的"写入内容"没绑到 `订单数据` 二维列表 |
| 数字变成 2.0 | 读取指令没勾"读取单元格显示的内容" |
| 文件被占用打不开 | 流程末尾加「关闭 Excel」释放对象 |
| 其他报错 | **底部日志区**完整报错截图发我，我帮你判 |
